# Peekaboo

Every file on your Mac, finally findable: a card-based library, search in plain English, and cleanup you can always undo.

**Download:** [Peekaboo.dmg](https://github.com/vishvavariya/peekaboo-releases/releases/latest/download/Peekaboo.dmg) · [getpeekaboo.app](https://getpeekaboo.app)

Requires macOS 14 or later. Signed with Developer ID and notarized by Apple.

Verify a download:

```bash
cd ~/Downloads && shasum -a 256 -c Peekaboo-*.dmg.sha256
```
